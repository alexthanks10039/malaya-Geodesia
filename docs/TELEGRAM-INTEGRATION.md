# Telegram integration — Малая геодезия

Источник модуля: GPT-GPT-Gpt / BOT TG. Интеграция выполнена внутрь Next.js-приложения, без отдельного backend.

## Поток
Калькулятор → POST /api/leads → Telegram Bot API → владелец → кнопки заявки → изменение статуса.

## ENV
TG_KEY=...
OWNER_ID=...

## Webhook
POST /api/telegram/webhook

## Команды
/start
/reload
Главное меню

## Внутри Telegram
- новые заявки
- заявки в работе
- статистика
- карточка заявки
- взять в работу
- изменить статус
- главное меню

## Ограничение текущего MLP
Хранилище заявок in-memory. После перезапуска Next.js процесса данные Telegram-статусов очищаются. Это сознательно не решаем на этапе текущей интеграции.

Mini App Flutter из исходного проекта не переносился как отдельное приложение: текущая задача — натянуть Telegram-операционный модуль на существующий веб-проект и калькулятор.
