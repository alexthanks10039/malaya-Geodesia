# Calculator modes

## Public / Preliminary
Customer-facing estimate. Minimal inputs, published customer-safe model, assumptions visible, no internal cost or margin. Result is explicitly preliminary.

## Internal / Detailed
Manager, engineer and finance workspace. Exact operational drivers, resource costs, rates, overhead, scenarios, margin and full trace.

Both modes use one deterministic Calculation Core. They are separated by model policy, input policy, output visibility and permissions, not by separate engines.

Historical calculations remain bound to their model version.
