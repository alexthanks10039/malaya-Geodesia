# Куб времени

Изолированный модуль исходного приложения «Куб времени» squirld.

## Структура

- `public/modules/time-cube/index.html` — исходный self-contained HTML-модуль.
- `app/time-cube/page.tsx` — Next.js-страница, которая показывает модуль по маршруту `/time-cube`.

Модуль оставлен отдельно от основного React-кода и текущей логики калькулятора. Видео обрабатывается на стороне браузера самим модулем.
